🧠 Showcase de Neuro-Animación

Visualización dinámica de redes neuronales para blogs académicos.

Cómo usar esto en tu blog

Sigue estos pasos para integrar la red neuronal dinámica en tus entradas de blog basadas en HTML.

  1. Añade el elemento Canvas donde quieras que aparezca la animación.
  2. Incluye el CSS para definir la altura del contenedor.
  3. Carga el script al final de tu etiqueta body.
<!-- 1. Contenedor de la Animación -->
<div style="height: 400px; background: #f8fafc; border-radius: 12px; overflow: hidden;">
  <canvas id="neuroCanvas"></canvas>
</div>

<!-- 2. Cargar el Script de Animación -->
<script src="assets/js/neuro-animation.js"></script>
